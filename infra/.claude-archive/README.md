# Archived Claude Code hooks

These hooks were active in the original `illidan53/ggame-infra` repo before
the infra was merged into this repo. They are preserved here for reference
only and are NOT active — Claude Code reads hooks from the repo-root
`.claude/hooks/` directory.

If you want to re-enable any of them, copy the script to `.claude/hooks/`
and register it in `.claude/settings.json` (or `settings.local.json`).
